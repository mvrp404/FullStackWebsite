## 🚀 Πώς να τρέξετε την εφαρμογή

### 1. Εκκίνηση Backend (FastAPI)
Ανοίξτε τερματικό στον φάκελο `backend` και τρέξτε:
```bash
python -m uvicorn main:app --reload
(Ο server θα τρέξει στο http://127.0.0.1:8000)

2. Εκκίνηση Frontend (React / Vite)
Ανοίξτε νέο τερματικό στον φάκελο frontend και τρέξτε:

Bash
npm install --legacy-peer-deps
npm run dev
(Η εφαρμογή θα ανοίξει στο http://localhost:5173)

✨ Λειτουργίες που έχουν υλοποιηθεί
Ασφάλεια & Ταυτοποίηση (Auth & RBAC):

Σύστημα εγγραφής και σύνδεσης με JWT Tokens και κρυπτογράφηση κωδικών (bcrypt).

Υποστήριξη ρόλων χρηστών: Administrator, Organizer, Participant (Guest), καθώς και δυνατότητα πλοήγησης ως απλός Επισκέπτης.

Έξυπνο σύστημα έγκρισης χρηστών (Ο πρώτος χρήστης-Admin εγκρίνεται αυτόματα (admin, admin123), ενώ οι επόμενοι οργανωτές απαιτούν έγκριση από τον διαχειριστή).

Διαχείριση Εκδηλώσεων & Εισιτηρίων:

Δημιουργία, προβολή, επεξεργασία, ακύρωση και διαχείριση εκδηλώσεων από πιστοποιημένους Διοργανωτές.

Έλεγχος χωρητικότητας και τύπων εισιτηρίων (διασφάλιση ότι τα εισιτήρια δεν υπερβαίνουν τη συνολική χωρητικότητα).

Αυτόματη ενημέρωση διαθεσιμότητας κατά την πραγματοποίηση κράτησης και αυτόματη αποστολή μηνυμάτων ακύρωσης.

Προηγμένα Χαρακτηριστικά:

Σύστημα Συστάσεων (Machine Learning): Υλοποίηση αλγορίθμου Biased Matrix Factorization εκ του μηδενός για προσωποποιημένες προτάσεις εκδηλώσεων βάσει ιστορικού κρατήσεων.

Εξαγωγή Δεδομένων: Δυνατότητα λήψης αρχείων JSON και XML (συμβατών με το απαιτούμενο DTD της εργασίας) απευθείας από το Admin Panel.

Εσωτερική Messaging Υπηρεσία: Οργάνωση σε Εισερχόμενα / Απεσταλμένα με ενδείξεις αδιάβαστων μηνυμάτων.

Χάρτες: Ενσωμάτωση OpenStreetMap για την οπτικοποίηση των γεωγραφικών συντεταγμένων των εκδηλώσεων.
